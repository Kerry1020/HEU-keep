# HEU-keep

HEU-keep is a web-based high-fidelity workout record generator tailored for Harbin Engineering University (HEU). It recreates the visual style of Keep running result pages and lets users edit workout data, preview the generated card in real time, draw or generate tracks, and export high-resolution images.

## Key Features
- High-fidelity Keep-style result-card rendering
- HEU map adaptation and multiple background styles
- Real-time data editing and preview
- Manual track drawing on canvas
- Random/local track generation support
- High-resolution image export via off-screen rendering optimization
- IndexedDB-based local persistence for user settings
