## Project Summary

HEU-keep is a Keep-style workout card generator adapted for Harbin Engineering University (HEU). It provides real-time data editing, visual preview, track drawing / generation, and high-resolution export.

This copy highlights **Kerry's frontend-focused role** in the project.
